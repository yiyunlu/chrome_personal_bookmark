## Conventions (read before composing)

- **Tokens, not colours.** Every colour is a Tailwind class over an `hsl(var(--ui-*))` token: `bg-card`, `text-foreground`, `text-muted-foreground`, `text-faint` (third text level: counts, URLs), `border-border`, `bg-primary` / `text-primary` (the blue accent), `bg-primary/10` (accent-soft chip), `bg-secondary`, `text-destructive`, `bg-scrim/40`. Never a hex, never a stock Tailwind palette colour, never an inline `style={{ color }}`. In raw CSS/inline style (previews only) write `hsl(var(--ui-primary))`.
- **Theme.** Dark mode is `<html data-theme="dark">` (not a `.dark` class). Tokens swap; classes don't change.
- **Type.** IBM Plex Sans, 13px base; IBM Plex Mono for URLs/domains at `text-[10.5px]`. CJK falls back to the system font (Noto Sans SC / PingFang) - not bundled. Labels are `text-sm font-medium`; section eyebrows `text-[11px] uppercase tracking-[.06em] text-faint`.
- **Radius scale.** `rounded-sm` 6 / `rounded-md` 8 / `rounded-lg` 9 / `rounded-xl` 9. Cards and dialogs are `rounded-xl`/`rounded-lg`; controls `rounded-md`; chips `rounded-sm`. Nothing else.
- **Buttons.** Always `<Button>`, never a raw `<button>`. `default` = the one primary action of a surface, `outline` secondary, `secondary` neutral fill, `ghost` icon-only and row actions, `destructive` confirmed destructive, `link` inline text. Sizes `sm | default | lg | icon`. Icons inside a Button take no size prop - the button sizes them (`[&_svg]:size-4`).
- **Merging classes.** Pass overrides through `cn()`; tailwind-merge drops conflicting classes silently (a later `text-*` deletes `leading-*`, `hover:` is its own group - restate `hover:bg-primary/10 hover:text-primary` when overriding a ghost Button's hover).
- **Compounds render as compositions.** Card = Card > CardHeader(CardTitle, CardDescription) > CardContent > CardFooter. Select/Dialog/AlertDialog/DropdownMenu/ContextMenu sub-parts only make sense inside their root; their preview cards show the full composition.
- **Overlays.** Dialog for edit/settings forms; AlertDialog for confirmations (Cancel autofocused, no backdrop dismiss); DropdownMenu for the "more" button and right-click menus (the app anchors it to the pointer); Tooltip for icon-only buttons (also give them `aria-label`). Toasts: `<Toaster theme=… position="bottom-right">` mounted once, then `toast.custom(...)` from `window.TabHub.toast` - the app's undo toast is a card with a `bg-primary/10 text-primary` Undo chip.
- **Layout idioms.** Bookmark tile = `<Card>` with 22px favicon/identity tile + title + mono domain, two lines. Collection = sticky header with count + actions over a grid of tiles (list view shows tags as `secondary` Badges). Sidebar = 220px rail on `bg-sidebar` with an accent-tinted active row.
- **i18n.** UI copy is zh-CN by default (en supported); keep labels short.
