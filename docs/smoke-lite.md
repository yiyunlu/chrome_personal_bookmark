# TabHub 精简 Smoke（无 Eddie）

面向验收 / Bot：在 **不依赖 Eddie 坐镇** 的情况下，对 `ui/shadcn-migration` 构建产物做一轮可勾选的浏览器冒烟。

## 边界（必读）

- **本剧本不替代** `SHADCN_MIGRATION.md` 里的全量 Manual smoke list。
- **全量手册 smoke 仍挡 merge**（含 PR #3 → `main`）。本剧本只证明「无 Eddie 也能独立跑完一批高风险项并留证据」。
- 自动化门禁（`npm test` / `scripts/verify-ui.sh` / CI）**测不到** 真拖拽、真实 popper 布局、扩展 runtime；下列项必须真人（或有 Chrome/扩展权限的验收）在本机点。

条目来源：自 `SHADCN_MIGRATION.md` Manual smoke list 抽出的高信号项（拖↔右键、对话框+Undo、Select 高度、dark 描边、嵌套确认、关键对话框 console）。

## 前置

1. 仓库：`/Users/eddielu/Canada_DEV/chrome_personal_bookmark`，分支 `ui/shadcn-migration`（或与待验 PR 相同 tip）。
2. `npm ci && npm run build`（或确认本地 `dist/` 与 tip 一致）。
3. Chrome → `chrome://extensions` → 开发者模式 → **加载已解压的扩展程序** → 选仓库根下的 `dist/`。
4. 打开一个新标签页（TabHub 新标签页）；开 **DevTools Console**，保持打开直到本轮结束。
5. **至少再开 1 个非扩展普通标签页**（例如 `https://example.com`）。不要只留 `chrome://` / 扩展页 / TabHub 新标签页——否则「保存当前标签页」拿不到可保存标签，第 2 / 6 / 8 条会假 FAIL。
6. 准备至少一个有书签的文件夹（可含子文件夹）；侧栏底栏能看到「回收站」「设置」。

## 清单（10 条）

### 1. 拖拽 ↔ 右键无 `removeChild`

- **前置**：主内容区可见至少 2 张书签卡片；Console 打开。
- **步骤**：拖动一张卡片排序 → 对该卡右键打开菜单 → 再拖一次（可拖回原位）。
- **期望**：无崩溃；Console **无** `removeChild` / NotFoundError；菜单可正常出现与关闭。
- **记录**：- [ ] PASS / FAIL：______

### 2. 对话框打开时 Undo 可点（鼠标）

- **前置**：有可删书签；记住 Undo 约 8s 窗口；已满足总前置第 5 条（至少 1 个普通标签）。
- **步骤**：删除一张卡片 → 待 Undo toast 出现 → 按 `S` 打开「保存当前标签页」→ **用鼠标**点 toast 上的「撤销」。
- **期望**：撤销生效（书签回来）；**对话框保持打开**（不因点 toast 被当成 outside click 关掉）。
- **记录**：- [ ] PASS / FAIL：______

### 3. 侧栏两个 Select：列表满高、不被裁切

- **前置**：侧栏展开。
- **步骤**：分别打开书签源 Select、语言 Select，观察弹出列表。
- **期望**：列表为多行满高（不是只剩一行高的 viewport）；不被侧栏/主区裁切；可滚动看全选项。
- **记录**：- [ ] PASS / FAIL：______

### 4. Dark 模式书签卡片描边

- **前置**：侧栏底栏主题按钮可点。
- **步骤**：切到 **深色**；浏览主区多张卡片外框。
- **期望**：卡片边框为主题边框色，**不是**近白 `#e5e7eb` 描边；浅色再切回确认仍正常。
- **记录**：- [ ] PASS / FAIL：______

### 5. 嵌套确认：回收站 → 清空回收站

- **前置**：回收站内至少有 1 项（可先删一张卡）。
- **入口（必读）**：只点 **侧栏底栏** 的「回收站」图标，打开应用内回收站面板。**禁止**点侧栏分类树里名为 `.TabHub Trash` 的文件夹（那是原生书签树节点，不是本条要验的面板）。
- **步骤**：底栏打开回收站面板 → 点「清空回收站」→ 出现确认层。
- **期望**：确认层叠在回收站面板**之上**；`Escape` 只关最上层确认；确认后可完成清空（或取消后两层行为符合预期）。
- **记录**：- [ ] PASS / FAIL：______

### 6. Save Tabs 打开一次 + Console 无红错

- **前置**：Console 已清或可区分新旧日志；已满足总前置第 5 条（至少 1 个普通标签），否则对话框可能打不开。
- **步骤**：工具栏打开「保存当前标签页」（或 `S`）；看面板与 Console；关掉。
- **期望**：对话框正常打开/关闭；此过程 Console **无红色 error**（已知测试里 mock 的无关日志不算）。
- **记录**：- [ ] PASS / FAIL：______

### 7. 设置打开一次 + Console 无红错

- **步骤**：侧栏底栏打开「设置」；扫一眼 API Key / 数据区；关闭。
- **期望**：面板完整可见（短窗口下也不应无意义裁切到不可用）；Console 无红错。
- **记录**：- [ ] PASS / FAIL：______

### 8. Save Tabs 内目标 Select：在对话框之上且列表完整

- **前置**：已满足总前置第 5 条，Save Tabs 对话框能打开。
- **步骤**：打开 Save Tabs → 打开目标文件夹下拉。
- **期望**：下拉层在对话框面板**之上**；显示**完整选项列表**（不是高度被压成一行）；选一项后**对话框不关**。
- **记录**：- [ ] PASS / FAIL：______

### 9. 右键菜单基础：换锚点不崩

- **步骤**：右键卡片 A 打开菜单 → **不先关掉**，再右键另一张卡片 B。
- **期望**：菜单移到 B，无白屏/崩溃；Console 无异常。
- **记录**：- [ ] PASS / FAIL：______

### 10. 回收站面板：Escape / 滚动

- **前置**：回收站项较多更好（可多删几张）；否则有 1+ 项即可。
- **入口（必读）**：与第 5 条相同——只走 **侧栏底栏「回收站」** 打开的应用内面板；**不要**打开分类里的 `.TabHub Trash`。
- **步骤**：底栏打开回收站面板；试 `Escape`；若列表长则滚动。
- **期望**：`Escape` 关闭回收站面板；长列表可滚、不裁切成不可见；焦点行为无明显卡死。
- **记录**：- [ ] PASS / FAIL：______
